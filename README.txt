LEARN WITH FAIQ — QUICK START
================================

This is a responsive, client-side learning website created by Faiq, with three complete paths:
• Phone Mastery — 12 lessons
• PC & Hardware Lab — 12 lessons
• Car Knowledge Garage — 12 lessons

WHAT'S INCLUDED
- 36 sequenced lessons with friendly explanations, analogies, diagrams, examples, misconception checks and expandable practice hints
- Three-question concept tests in every lesson, instant answer explanations, a 2/3 pass threshold and retries
- Course outline, lesson navigation, search, a 40-term dictionary and a progress dashboard
- Personal lesson notes, saved progress, streak/activity tracking and JSON export
- Click-to-open YouTube visual explainers and links to official/technical references
- Responsive desktop/tablet/mobile layout and dark mode

HOW TO OPEN
1. Extract techtrail-academy.zip to a folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. Use the left menu to select a course. Start with lesson 1 and complete the concept check.

IMPORTANT NOTES
- Lessons, diagrams, quizzes, course navigation and search run locally in your browser.
- Progress and notes are saved in the browser's local storage for the current browser/profile/device. Use “Export my progress” to download a JSON backup and “Restore progress backup” on the Progress page to import it later. Restoring replaces the current local progress after confirmation. They do not automatically sync across devices. If the browser blocks local storage for a local file, your progress still works in the open session; export it before closing.
- YouTube previews and external references require an internet connection. Videos open on YouTube when clicked; the page does not load embedded players automatically.
- Open-source pages and model specifications can change. Verify exact product variants, current policies, local laws, prices and car safety assessments with the relevant official source before making a purchase or safety decision.
- This is an educational resource, not a replacement for a qualified mechanic, professional builder, vehicle owner manual or official regulatory guidance.
